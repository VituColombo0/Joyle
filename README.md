# Joyle Deep Tech - Website Institucional

Este repositório contém o código-fonte do website institucional da **Joyle Deep Tech**, desenvolvido como uma solução moderna, performática e visualmente impactante para representar a vanguarda da pesquisa científica em materiais avançados.

## 🔬 Sobre a Joyle Deep Tech

A **Joyle Deep Tech** é uma empresa dedicada à pesquisa científica aplicada, com foco especial no desenvolvimento de materiais poliméricos avançados. A empresa atua na intersecção entre a ciência fundamental e a aplicação industrial, transformando descobertas moleculares em soluções reais para desafios complexos de engenharia e sustentabilidade.

### Áreas de Atuação:
- **Pesquisa Molecular:** Formulação e design de polímeros em nível atômico.
- **Desenvolvimento de Materiais:** Criação de novos compostos com propriedades específicas (resistência, flexibilidade, condutividade).
- **Consultoria Científica:** Apoio estratégico para indústrias que buscam inovação através da ciência de materiais.

## 🌐 O Projeto

O website foi construído utilizando as melhores práticas de desenvolvimento front-end para garantir uma experiência de usuário (UX) premium:

- **Design Moderno:** Estética Dark Mode com acentos em verde neon, refletindo tecnologia e biotecnologia.
- **Background Dinâmico:** Hero section com imagem de alta definição e overlays químicos integrados sutilmente.
- **Performance:** Código limpo e otimizado (HTML5/CSS3/JS Vanilla) para carregamento instantâneo.
- **Responsividade:** Totalmente adaptado para dispositivos móveis, tablets e desktops.
